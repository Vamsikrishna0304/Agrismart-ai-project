# AgriSmart AI – Smart Agriculture Assistant

An AI-assisted agriculture platform designed to help farmers explore crop suitability, plant disease analysis, irrigation recommendations, farm monitoring, and farming information.

## Live Demo

https://agri-fabulous-smart-grow.base44.app/

## Features

- Farm dashboard and farm records
- Crop suitability recommendations
- Plant disease analysis
- Rule-based irrigation recommendations
- Farm sensor monitoring and simulated sensor readings
- Agriculture assistant and alerts

## Technology Stack

- React and JavaScript (JSX)
- Base44 SDK
- TypeScript utilities
- Base44 backend functions

## Important Limitations

- Crop suitability uses a rule-based scoring system, not a trained machine-learning model.
- Irrigation recommendations use transparent threshold-based rules.
- Simulated sensor readings are demonstration data and are not real IoT hardware measurements.
